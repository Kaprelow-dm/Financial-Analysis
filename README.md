# Комплексный финансовый анализ предприятия (2021–2023 гг.)

Данный проект представляет собой полноценный аналитический обзор финансово-хозяйственной деятельности предприятия на основе данных бухгалтерской отчетности за 3 года (название изменено в целях конфиденциальности).

## 📌 О проекте
Проект охватывает 16 аналитических блоков и базируется на данных бухгалтерской отчетности (Формы №1–5).

**Инструменты:**
*   Microsoft Excel (продвинутое моделирование, формулы, факторный анализ)
*   Финансовый анализ (горизонтальный, вертикальный, коэффициентный)
*   Визуализация данных и построение графиков с помощью Python (Matplotlib, Pandas)

## 📊 Ключевые выводы
*   **Преодоление кризиса:** Несмотря на убыток 2022 года (-20,9 млн руб.), вызванный геополитическими факторами и ростом прочих расходов, в 2023 году компания вышла в прибыль (12,6 млн руб.).
*   **Дисбаланс в трудовых ресурсах:** Темпы роста ФОТ (+33,4%) и заработной платы (+18%) опережают темпы роста производительности труда (+92% к базе). Это требует пересмотра кадровой политики.
*   **Зона риска (Ликвидность):** Дефицит собственных оборотных средств и снижение коэффициента абсолютной ликвидности до 0,475 указывают на зависимость от заемного капитала.
*   **Деловая активность:** Ускорение оборачиваемости запасов (с 476 до 372 дней) при сохранении высокой доли дебиторской задолженности (482 дня).

## 📂 Файлы проекта
*   [`Analysis.xlsx`](Analysis.xlsx) — Excel-файл с 16 таблицами расчетов, факторным анализом и прозрачной логикой формул.
*   [`Report.pdf`](Report.pdf) — Подробный текстовый отчет по результатам анализа.
